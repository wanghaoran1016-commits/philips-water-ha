# 【测试版】飞利浦 i2 Pro 接入 Home Assistant / HomeKit：制冷、水温、水量档位控制

最近在折腾飞利浦冰境 i2 Pro（ADD8666/93）接入 HA，在 hlhk2017 的 deerma_water 开源项目基础上，结合自己设备的诊断和操作对照，做了一个社区增强测试版，分享给有同款设备的朋友一起测试。

原项目：https://github.com/hlhk2017/deerma_water
本项目：https://github.com/wanghaoran1016-commits/philips-water-ha

感谢原作者，保留 MIT 许可证和原作者版权。本项目非飞利浦官方集成。

目前实现了制冷模式（关闭、仅冰水、小冰和冰水、大冰和冰水）、水温档位（冰水、凉水、常温及45/55/75/85/100℃）、水量档位（120/150/250/350/500/800 mL及连续），以及饮用水TDS、五合一滤芯寿命读取。蜂鸣声开关也保留在HA。

水量各档位已在自己的设备上测试正常。75/85/100℃曾出现映射问题，b7及b8已经修正，修正后仍需要进一步复测。制冷模式读取与App一致，所有制冷组合写入、HomeKit各档位控制尚未完成完整验证。

HomeKit通过HA的HomeKit Bridge接入，选择Select域的三个控制实体即可。苹果家庭会显示为三个排插式开关组，不是原生饮水机面板，目前已经成功显示。每个档位一个按钮，外观比较朴素，也可以自己建常用场景。

特别说明：水温和水量只是设置档位，不会自动出水。累计用水量、水质“优”等等级、自定义槽位、清洗、童锁等暂未适配，不建议按全功能稳定版使用。依赖厂商云服务。

安装：GitHub点Code → Download ZIP，解压，将custom_components/deerma_water放入HA的/config/custom_components/，重启后添加“飞利浦水健康”。已有原版先备份，不要同时安装同名domain的两个版本。详细安装、升级及HomeKit步骤见仓库README。

目前实测环境为一台i2 Pro、HA Container 2026.10.1，32项离线测试通过，其他机型兼容性未知。欢迎同款用户反馈型号、HA版本、集成版本、具体操作及App/HA的对应结果。请不要公开账号、令牌、完整抓包或HA备份；诊断上传前也请检查隐私。
