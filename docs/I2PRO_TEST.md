# i2 Pro 实机验证与制冰适配

## 先确认安装

记录：HA Core 版本、设备铭牌型号（例如 ADD8666/93）、设备固件版本。不要拍摄或分享序列号、MAC、账号二维码。先确认官方 App 能正常控制。

安装后，设置 → 设备与服务 → 飞利浦水健康 → 配置项菜单 → 下载诊断（具体菜单位置以 HA 版本为准）。如果该入口不存在或集成无法加载，发错误文字及 HA 版本，不要先开全量调试日志。

## 第一阶段：只读

1. 等待约 30–60 秒，下载诊断，命名 `01_idle.json`。
2. 查看 `connection_live` 是否为 true；false 时先排查连接，不做控制测试。
3. 核对 `control_mappings` 的温度、水量是否与官方 App 一致。
4. 先不操作 HA 的设置按钮。

插件诊断仅包含：连接是否新鲜、已知温度／水量映射、设备字段名与类型、白名单数值。不会复制配置项或整个云端响应。HA 自身可能在外层添加系统元数据，分享前仍可检查文件；完整日志和 HA 备份不属于本流程。

## 第二阶段：用官方 App 改变制冰状态

1. 确保机器状态正常，在官方 App 手动开启制冰。不要为了测试断电、绕过缺水或其他保护。
2. 等待约 15–30 秒，再下载诊断，命名 `02_ice_on.json`。
3. 如官方 App 允许停止制冰，正常停止后再下载 `03_ice_off.json`；若不能停止，不要强行中断，记录该限制即可。
4. 单独记录这次点了哪个按钮、前后状态是什么。不需要提供登录过程。
5. 如果能选大／小冰，再分别采集，**一次只改变一个选项**。

诊断可确定返回状态的字段变化，**不能单凭状态差异证明相同字段可写，也不能确定命令 payload**。如果状态数据不足，下一轮需要检查官方 App 对应的控制请求；届时只提取已脱敏的单条设备指令，不上传完整 HAR。

后续开发顺序：确认型号 → 确认状态与命令 → 为该型号增加专用 profile → 添加离线测试 → 本机验证 → HomeKit 桥接。不会为所有飞利浦型号通用写入未知字段。
