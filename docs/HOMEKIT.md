# i2 Pro：只桥接三个控制实体

本版保留三个 select：制冷模式、水温档位、水量档位。HomeKit Bridge 将每个 select 表示为多开关附件，每个选项一个按钮；不是原生饮水机完整面板，具体展示取决于苹果家庭版本。蜂鸣声设为 HA 配置实体，默认自动发现桥接时排除；显式包含仍会桥接，所以最终以桥接筛选为准。

## 已有 HomeKit Bridge

1. 安装 b8 后重启 HA，确认设备页面有制冷模式、水温档位、水量档位。
2. 设置 → 设备与服务 → HomeKit Bridge → 配置/选项。保留桥接中其他设备原来的选择。
3. 保持已有桥接的包含/排除模式，添加 Select（选择器）域，其他类型保持原样。若是 include，下一页勾选要接入的实体；若是 exclude，下一页勾选的是要排除的实体，不要勾选三个目标选择器。
4. 根据上一步模式保留三个目标选择器，排除蜂鸣声、采集控制变化和其他不需要的实体。设备触发器页可留空。
5. 如果此前显式包含了蜂鸣声，将其移出包含列表或加入排除列表。提交后等待家庭同步，无需删除整个桥接或重新配对。
6. 已在家庭中显示的旧名称可能被缓存，可在家庭内改名为“饮水机制冷”“饮水机水温”“饮水机水量”。HA 内用户自定义的名称也不会被强行覆盖。

## 尚未建立桥接

设置 → 设备与服务 → 添加集成 → HomeKit Bridge，模式选择 Bridge，包含类型 Select，实体只选上述三个。完成后使用iPhone家庭扫描HA通知/配置中提供的配对二维码。不要为已桥接的相同实体重复创建桥接。

## 操作含义

- 制冷模式“关闭”关闭制冷功能，不是整机断电。
- 温度和水量只改档位，不发送开始出水指令。“连续”也是水量档位。
- 一组选项里选择目标档位；不要把每个选项当成独立电源，不要对整组选项执行全部打开/全部关闭自动化。
- 档位温度已按b7实机反馈修正：75℃=205、85℃=203、100℃=204。
- TDS、滤芯、统计留在HA。水质等级、累计用水和自定义槽位尚未完成。

## 验证

家庭中选择常温和250 mL，观察HA与官方App同步；再试制冷模式。已有用户截图确认三个选择器在苹果家庭显示为排插式开关组；完整家庭端控制仍待验证。
