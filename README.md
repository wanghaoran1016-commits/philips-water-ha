# 飞利浦水健康 · Home Assistant 社区集成

**0.2.0b8 · 公开测试版**，目前主要针对飞利浦冰境 i2 Pro（ADD8666/93）进行适配。不是飞利浦官方集成，依赖厂商云服务，不是本地离线控制。

基于 [hlhk2017/deerma_water](https://github.com/hlhk2017/deerma_water) 开发，感谢原作者的开源成果。保留 MIT 许可证与版权声明，来源见 [NOTICE.md](NOTICE.md)。增强版问题请提交到本仓库，不要要求上游作者承担维护。

## 功能与验证范围

| 功能 | 当前情况 |
|---|---|
| 制冷模式 | 已实现关闭、仅冰水、小冰和冰水、大冰和冰水；模式读取与官方 App 对照过，HA/HomeKit 全模式写入仍待完整复核 |
| 水温档位 | 已实现冰水、凉水、常温、45/55/75/85/100℃；75/85/100℃按实机反馈修正，修正后三档仍待复测 |
| 水量档位 | 120/150/250/350/500/800 mL、连续；用户反馈 HA 各档位均正常 |
| 饮用水 TDS | 已读取，并与官方 App 的数值对照 |
| 五合一滤芯寿命 | 已读取设备 PC5in1FilterLife 字段，长期变化待验证 |
| 蜂鸣声 | 已实现开关，保留在 HA 配置类别，默认不自动桥接；完整写入测试待复核 |
| HomeKit Bridge | 三个选择器已在苹果家庭显示，呈现为排插式开关组；尚未完整验证家庭端所有档位控制 |
| 诊断 | 可选的五分钟控制变化采集；只导出白名单数据 |

当前实机反馈来自一台 i2 Pro，HA Container 2026.10.1。其他型号、固件、账号区域未验证。i2 Pro 控制采用字段特征识别，不能据此保证所有相同字段设备兼容。

**水温、水量只设置档位，不会自动出水。** 官方 App 自定义温度/水量槽位尚未适配，修改这些自定义参数可能导致标签与实际含义不一致。

## 尚未支持 / 已知限制

- 开始出水、清洗、排水、滤芯复位、童锁写入和制冷定时等未实现。
- 饮用水水质“优”等等级没有确认的字段或分级规则，不根据 TDS 猜测。
- i2 Pro 累计用水量尚未适配，旧总用水量实体显示不可用；不将原始 TotalOutlet 直接换算成升。
- i2 Pro 缺少自来水 TDS、AQP 滤芯字段时，会禁用对应旧实体并保留历史记录。
- 云端连接、网络或令牌失效会影响控制；超时不自动重发，请先查看官方 App 是否已经生效。
- 不是全功能稳定版；离线测试不能替代实际 HA、云端、设备和 HomeKit 测试。

## 手动安装

1. 在“飞利浦水健康”官方 App 中绑定设备，确认在线。备份 Home Assistant。
2. 点击本仓库 **Code → Download ZIP**，解压；不要直接把整个 ZIP 上传到 custom_components。
3. 将其中的 `custom_components/deerma_water` 文件夹复制到 `/config/custom_components/`。
4. 确认路径为 `/config/custom_components/deerma_water/manifest.json`，不要多套一层目录。
5. 重启 Home Assistant。在“设置 → 设备与服务 → 添加集成”搜索“飞利浦水健康”。
6. 在自己的 HA 中输入账号，选择密码或短信验证码登录，再选择设备。不要把密码、验证码发给开发者。
7. 先在 HA 设置常温、250 mL，与官方 App 对照，再逐项验证其他档位，无需实际出水。

已有本集成时，备份旧目录后完整替换 `deerma_water` 文件夹并重启，无需删除设备。不要同时安装相同 domain 的原版和增强版。原版配置迁移到版本 2 后，回退应恢复备份，不能只覆盖旧代码。

HACS 元数据已包含，但 HACS 安装流程尚未验证，也未收录到默认商店；本测试版优先手动安装。

## 接入苹果家庭

通过 HA 的 **HomeKit Bridge** 桥接 `Select` 域中的“制冷模式”“水温档位”“水量档位”。蜂鸣声不需要桥接。

苹果家庭显示为三个排插式开关组，每个选项一个开关，选中档位显示“1个开着”，不是原生饮水机面板。HA 图标不能改变苹果家庭的面板布局。完整步骤见 [HomeKit 指南](docs/HOMEKIT.md)。

不要对整组选项执行“全部打开/关闭”；停止制冷应选择制冷模式里的“关闭”。常用温度和水量可组合成场景，但仍不自动出水。
